# 暮らしの助けになるお金の情報（川崎市）

川崎市の給付金・助成金・締切のある申込募集を集めたサイトです。
公開ページ: https://tkbworks.github.io/kawasaki_money/

## 仕組み

```
市政だより（テキスト版）などの公開情報
  → 基準に沿って選別し、データ（JSON）に整形
  → 生成スクリプトがページ（HTML）を組み立て
  → GitHub Pagesで公開
```

- `items-YYYY-MM.json` — 収集した項目のデータ。タイトル、金額、締切、概要、公式ページへのリンクを持つ
- `build_site.py` — データから公開ページを生成するスクリプト
  - 使い方: `python3 build_site.py items-2026-11.json <出力先フォルダ> [YYYY-MM-DD]`
  - 締切が基準日以降（または締切なし）の項目は現行ページ `index.html` へ、締切を過ぎた項目は `archive.html`（「過去の情報」）へ振り分ける

## 収集の基準

- 対象: 給付金・助成金・手当などの「もらえる」お金、減免・割引などの「安くなる」もの、料金が明示され締切のある市の制度の利用者募集
- 対象外: イベント・講座・コンサート類（有料・無料・招待を問わず）、健診・相談会、景品が当たるもの
- 表示は「もらえる（給付・助成）」と「支払う・申し込む（利用・購入）」に分けている
- 締切を過ぎた項目は削除せず、「過去の情報」に「締め切り済み」と表示して残す（毎年・隔年で繰り返される募集が多いため）

## 情報源

- かわさき市政だより（全市版・全区版のテキスト版）
- 各区のお知らせ

制度の詳細・最新情報は、各項目に付けた公式ページで確認してください。
対象かどうかの判定や申込の支援は行っていません（集めて公開するだけのサイトです）。
